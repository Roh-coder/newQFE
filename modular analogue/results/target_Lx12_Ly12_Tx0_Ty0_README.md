# Modular anchored-ratio heatmaps

Target geometry: (12, 12, 0, 0)

Target tau: 0.500000000000 + 0.866025403784 i

Anchor choice: nu_anchor = tau / 8.000

Observable set:
- v/4 anchored to nu_anchor
- u/4 anchored to nu_anchor
- w/4 anchored to nu_anchor
- (v/4)/(u/4)
- (w/4)/(u/4)

Signed panels use log residuals relative to the target tau. Positive panels use squared log residuals and summed sector scores.
